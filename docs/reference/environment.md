# Environment Variables

These values are validated by `env.schema.ts` at startup.

| Variable                                  | Required                                | Example                                                                 | Used by                                                                                                                                                       |
| ----------------------------------------- | --------------------------------------- | ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PORT`                                    | Optional (default 3000)                 | `3000`                                                                  | Server listen port in `main.ts`; used by `MockPaymentProvider` to build payment links.                                                                        |
| `DATABASE_URL`                            | Required                                | `postgresql://postgres:postgres@localhost:5432/hivepoint?schema=public` | Prisma database connection.                                                                                                                                   |
| `JWT_ACCESS_SECRET`                       | Required                                | `change-me`                                                             | JWT access signing in `AuthService` and verification in `JwtGuard`/`OptionalJwtGuard`.                                                                        |
| `JWT_REFRESH_SECRET`                      | Required                                | `change-me`                                                             | JWT refresh signing and verification in `AuthService`.                                                                                                        |
| `JWT_ACCESS_TTL_SECONDS`                  | Required                                | `900`                                                                   | Access token TTL in `AuthService`.                                                                                                                            |
| `JWT_REFRESH_TTL_SECONDS`                 | Required                                | `2592000`                                                               | Refresh token TTL in `AuthService`; refresh cookie max-age.                                                                                                   |
| `CORS_ORIGINS`                            | Required                                | `http://localhost:5173`                                                 | CORS setup in `main.ts` (comma-separated list).                                                                                                               |
| `COOKIE_DOMAIN`                           | Optional                                | empty or `example.com`                                                  | Refresh cookie domain in `AuthController`.                                                                                                                    |
| `COOKIE_SECURE`                           | Optional (default false)                | `false`                                                                 | Refresh cookie `secure` flag in `AuthController`.                                                                                                             |
| `ALLOW_PRIVATE_NETWORK_TARGETS`           | Optional (default false)                | `false`                                                                 | Allows `localhost`, RFC1918/private IPs, and other non-public network targets for OpenAPI fetches and gateway upstream calls. Enable for local dev/test only. |
| `REDIS_URL`                               | Optional                                | `redis://localhost:6379`                                                | Not used in code yet.                                                                                                                                         |
| `PAYMENT_PROVIDER`                        | Optional (default `MOCK`)               | `MOCK` or `STRIPE`                                                      | Selects the payment provider used by `/billing/subscribe`.                                                                                                    |
| `MOCK_PAYMENT_SECRET`                     | Required                                | `change-me`                                                             | Mock payment guard header validation.                                                                                                                         |
| `STRIPE_SECRET_KEY`                       | Required when `PAYMENT_PROVIDER=STRIPE` | `sk_test_...`                                                           | Stripe SDK client initialization and checkout session creation.                                                                                               |
| `STRIPE_WEBHOOK_SECRET`                   | Required when `PAYMENT_PROVIDER=STRIPE` | `whsec_...`                                                             | Stripe webhook signature verification on `/billing/stripe/webhook`.                                                                                           |
| `STRIPE_CHECKOUT_SUCCESS_URL`             | Required when `PAYMENT_PROVIDER=STRIPE` | `http://localhost:5173/billing/success`                                 | Checkout success redirect URL. `session_id` is appended automatically.                                                                                        |
| `STRIPE_CHECKOUT_CANCEL_URL`              | Required when `PAYMENT_PROVIDER=STRIPE` | `http://localhost:5173/billing/cancel`                                  | Checkout cancel redirect URL.                                                                                                                                 |
| `STRIPE_PORTAL_RETURN_URL`                | Required when `PAYMENT_PROVIDER=STRIPE` | `http://localhost:5173/billing`                                         | Return URL used by Stripe customer portal.                                                                                                                    |
| `BILLING_GRACE_PERIOD_DAYS`               | Optional (default `3`)                  | `3`                                                                     | Number of days a `PAST_DUE` subscription can keep access before entitlement is denied.                                                                        |
| `BILLING_RECONCILIATION_ENABLED`          | Optional (default `true`)               | `true`                                                                  | Enables the background Stripe reconciliation worker for subscriptions and renewal invoices.                                                                   |
| `BILLING_RECONCILIATION_INTERVAL_SECONDS` | Optional (default `300`)                | `300`                                                                   | Interval between reconciliation cycles when Stripe billing is enabled.                                                                                        |
| `BILLING_RECONCILIATION_BATCH_SIZE`       | Optional (default `25`)                 | `25`                                                                    | Maximum number of Stripe subscriptions reconciled per cycle.                                                                                                  |
| `BILLING_MANAGED_RETRY_ENABLED`           | Optional (default `true`)               | `true`                                                                  | Enables the app-managed renewal retry worker that manually re-attempts Stripe `PAST_DUE` renewal invoices according to the configured delay policy.           |
| `BILLING_MANAGED_RETRY_INTERVAL_SECONDS`  | Optional (default `60`)                 | `60`                                                                    | Interval between managed renewal retry worker cycles when Stripe billing is enabled.                                                                          |
| `BILLING_MANAGED_RETRY_BATCH_SIZE`        | Optional (default `25`)                 | `25`                                                                    | Maximum number of `PAST_DUE` Stripe renewal invoices retried per worker cycle.                                                                               |
| `BILLING_MANAGED_RETRY_DELAYS_MINUTES`    | Optional (default `60,360,1440`)        | `60,360,1440`                                                           | Comma-separated delay schedule for managed renewal retries. The first value schedules the first retry after a renewal fails; each later value schedules the next retry after the previous app-managed attempt. |
| `API_KEY_SALT`                            | Required                                | `change-me`                                                             | API key hashing in `KeysService`.                                                                                                                             |
| `USAGE_INGEST_SECRET`                     | Required                                | `change-me`                                                             | Usage ingest header validation in `UsageService`.                                                                                                             |
| `USAGE_INGEST_QUEUE_ENABLED`              | Optional (default `true`)               | `true`                                                                  | Enables queue-backed `/usage/record` ingestion and the background worker that drains queued usage events into `UsageRecord`.                                  |
| `USAGE_INGEST_QUEUE_INTERVAL_SECONDS`     | Optional (default `10`)                 | `10`                                                                    | Interval between usage ingest worker cycles when queue-backed ingestion is enabled.                                                                           |
| `USAGE_INGEST_QUEUE_BATCH_SIZE`           | Optional (default `100`)                | `100`                                                                   | Maximum number of queued usage events drained into `UsageRecord` per worker cycle.                                                                            |
| `ALERT_DELIVERY_ENABLED`                  | Optional (default `false`)              | `true`                                                                  | Enables the background operational-alert delivery worker.                                                                                                     |
| `ALERT_DELIVERY_WEBHOOK_URL`              | Required when `ALERT_DELIVERY_ENABLED=true` | `https://alerts.example.com/hivepoint`                               | External webhook target used by the alert delivery worker for active/reminder incident notifications.                                                         |
| `ALERT_DELIVERY_INTERVAL_SECONDS`         | Optional (default `60`)                 | `60`                                                                    | Interval between operational alert delivery cycles when external delivery is enabled.                                                                         |
| `ALERT_DELIVERY_COOLDOWN_SECONDS`         | Optional (default `900`)                | `900`                                                                   | Minimum time before re-sending an unchanged alert as a reminder.                                                                                              |
| `ALERT_DELIVERY_TIMEOUT_MS`               | Optional (default `10000`)              | `10000`                                                                 | HTTP timeout applied to outbound operational alert webhook delivery.                                                                                          |
| `GATEWAY_UPSTREAM_TIMEOUT_MS`             | Optional (default `15000`)              | `15000`                                                                 | Maximum time the gateway waits for the upstream HTTP response before failing the request.                                                                     |
| `GATEWAY_REQUEST_BODY_LIMIT_BYTES`        | Optional (default `262144`)             | `262144`                                                                | Maximum buffered request body size that the gateway forwards upstream.                                                                                        |
| `GATEWAY_RESPONSE_BODY_LIMIT_BYTES`       | Optional (default `1048576`)            | `1048576`                                                               | Maximum buffered upstream response body size that the gateway accepts before failing the request.                                                             |
